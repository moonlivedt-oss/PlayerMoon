Начинать новую сессию отсюда, а не с чтения кода.

|---|---|---|
| 0 | Макет `mockup/index.html` и спецификация (`SETTINGS.md`, `LAYOUTS.md`, `ANIMATIONS.md`, `themes/`, схема) | готово |

| 4 | Скорость с сохранением тона, кроссфейд, плавный старт/пауза, SMTC для RadialMenu | не начат |

## Этап 1: что проверено и как

- `pm_tests` (Linux и Windows-сборка под Wine): 39 тестов, 370 проверок, 0 провалов. Покрыты: JSON, схема тем,
  5 встроенных тем, импорт своей темы, палитра обложки (сверена с браузером), пружина (сверена с ANIMATIONS.md),
  кривые, плейлист и перемешивание, теги MP3/FLAC/WAV, БПФ, `state.json`, движок на null-бэкенде, раскладка
  «Классика» против координат макета, ноль кадров в покое, переходы плейлиста и мини-режима, бегущая строка,
  визуализатор, перевод дуг SVG в кривые.
- Ядро и интерфейс без окон проверены под TSan и ASan+UBSan.
- `PlayerMoon.exe` собирается mingw-w64 без предупреждений (`-Wall -Wextra -Wshadow -Werror`).
- Окно запущено под Wine 9 в Xvfb: загрузка папки, игра, плейлист, мини-режим, возврат, пауза, закрытие с
  записью `state.json`, восстановление при запуске, пустое состояние, 5 тем. Wine не умеет слои D2D,
  эффекты (тень, размытие), прозрачность в градиентах и заливку фигур градиентом - эти места проверяются
  только на Windows.

## Ручная проверка на Windows 11 (не сделана)

- Акрил под окном, тёмная/светлая рамка, скругление углов; Windows 10 - сплошной фон.
- DPI 100/125/150%, перенос окна между мониторами с разным DPI.
- Медиаклавиши с фокусом и без, вместе с другим плеером.
- Каждая анимация из списка в README, 5 тем, импорт и экспорт темы, сохранение между запусками.
- Нагрузка в Диспетчере задач: в покое 0% CPU и GPU, при игре в полном режиме - кадры только пока видно окно.
- Обложки из настоящих MP3/FLAC (JPEG и PNG), маска бегущей строки, тени и подсветка обложки.

## Решения (не пересматривать без причины)

- Рендер: D3D11 + DXGI swap chain для композиции + D2D 1.1 + DirectComposition. Если DComp недоступна -
  swap chain окна без прозрачности (акрил выключается).
- Своя рамка: `WM_NCCALCSIZE` -> 0, заголовок рисуем сами, `WS_CAPTION` оставлен ради системной тени и углов.
  Углы и тень окна системные для всех тем (этап 1); маленький радиус темы - малое скругление.
- Рост окна (плейлист, мини-режим) - мгновенный `SetWindowPos`, анимируется содержимое (решение пользователя).
- Темы, импорт и экспорт на этапе 1 - меню по правому клику (решение пользователя).
- Ядро - отдельная статическая библиотека с узким API (`core/player.h`, совместим с C++17). Для RadialMenu
  рекомендован отдельный процесс и управление через SMTC (этап 4), канал `\\.\pipe\PlayerMoon` - позже.
- JSON и проверка схемы - свои; схема `assets/theme-schema.json` - единственный источник правил.
- Дуги SVG в иконках переводятся в кривые Безье своим кодом (`view/svg_arc.*`), не `AddArc`.
- Обложка рисуется заливкой скруглённой рамки кистями (без слоёв D2D): дешевле и сама обрезается.
- Нет звукового устройства - плеер работает молча (null-бэкенд) и показывает предупреждение.
- `state.json` рядом с exe, если папка доступна на запись, иначе `%APPDATA%\PlayerMoon`.

## Временные замены этапа 1 (снимаются на этапах 2-3)

- Все темы рисуются раскладкой «Классика»; геометрия берётся из `layouts.json` для `classic`.
- Смена обложки - только «Наплыв», текста - только «Подъём»; визуализатор - только «Зеркало».
- `coverblur` рисуется как `cover`.
- Нет свечения заголовка (`titleGlow`) и свечения полос визуализатора (`vizGlow`).
- Внутренние тени (`inset`) с размытием - упрощённо, кольцом.
- Нет полосы прокрутки в плейлисте (прокрутка колесом).
- Нет иконки приложения (нужен .ico 16/24/32/48/256).

## С чего начать этап 2

1. Окно настроек: отдельное окно или панель поверх (решить с пользователем), вкладки по `mockup/SETTINGS.md`.
2. Смены обложки и текста: варианты в `view/player_view.cpp` (`OnTrackChanged`, `SwapLine`), отрисовка в
   `ui/painter.cpp` (`DrawCover`, `DrawLine`).
3. Визуализаторы: модель общая (`view/visualizer.*`), стили - в `Painter::DrawVisualizer` по `drawStrip` из макета.
4. `coverblur`: эффект Gaussian Blur над картинкой обложки, кэш по serial и размеру окна.

## Сборка и проверка

- Windows: `build.cmd`, тесты `build.cmd test`.
- Linux: `cmake -S . -B build-linux -G Ninja && cmake --build build-linux && ./build-linux/pm_tests`.
- Кросс-сборка: `tools/cross-build.sh`. Запуск под Wine: `wine64` с `LANG=C.UTF-8` (иначе не видны файлы
  с кириллицей в имени) и ALSA null-устройством, если в системе нет звука.
